    Lab path: beginner → automation → topology-as-code

    1. 1 · Foundations

      Complete early NetAutLabs modules. Practice SSH login, show commands, and reading running-config. Parallel: skim Cisco DevNet “Programming Basics”.

    2. 2 · Scripted changes

      Write small Netmiko scripts: backup config, apply a VLAN/ACL change, verify with show commands. Always keep a local backup file.

    3. 3 · Structured automation

      Add Ansible roles or simple NAPALM/Netmiko wrappers. Use inventory files; never hard-code credentials in scripts you share.

    4. 4 · Topology-as-code

      Build a Containerlab or netlab topology that mirrors a slice of production. Rehearse changes there before production windows.

      Netmiko quick-start cheat sheet

      # pip install netmiko
from netmiko import ConnectHandler

device = {
    "device_type": "cisco_ios",  # or juniper, arista_eos, ...
    "host": "192.0.2.10",
    "username": "admin",
    "password": "REDACTED",
    # "secret": "enable_secret",  # if needed
}

with ConnectHandler(**device) as conn:
    conn.enable()  # if enable/secret required
    # Backup
    running = conn.send_command("show running-config")
    open("backup.cfg", "w").write(running)

    # Change (send_config_set auto-enters config mode)
    output = conn.send_config_set([
        "interface GigabitEthernet0/1",
        "description lab-uplink",
        "no shutdown",
    ])
    print(output)

    # Save
    conn.save_config()
    # Verify
    print(conn.send_command("show interfaces description"))
      • Prefer vault / env vars for passwords — never commit secrets.
      • Use send_command_timing for prompts that hang on paging; disable paging (terminal length 0) early.
      • Check supported device_type values for your vendor.

      Common protocols cheat sheet

      Protocol / tool What it’s for When to use
      SSH Interactive CLI + scripted sessions (Netmiko) Day-to-day show/config on almost every box
      NETCONF XML RPC over SSH; structured config/state Vendor supports YANG models; need transactional edits
      RESTCONF HTTP REST over YANG models API-friendly automation; controllers & modern platforms
      Ansible Agentless playbooks / roles (often SSH) Fleet changes, idempotent workflows, team playbooks
      gNMI / gRPC Modern telemetry & config (where supported) Streaming telemetry, cloud-native NOS
